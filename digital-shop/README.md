# درس ۲ | راه‌اندازی فروشگاه تلگرام با پرداخت استارز

در قسمت اول رباتت را در BotFather ساختی. در این قسمت عکس و معرفی ربات را تنظیم می‌کنی، قالب RR Bot Academy را به آن وصل می‌کنی و یک سفارش را از پرداخت رسمی تلگرام تا تحویل پیگیری می‌کنی.

**پیش‌نیازها** ربات قسمت اول، توکن آن، یک ایمیل در دسترس و برنامهٔ Telegram روی گوشی. GitHub و Cloudflare را با مرورگر همان گوشی باز می‌کنی. [قسمت اول | ساخت ربات در BotFather](https://github.com/rrdigitalhub01-arch/rr-bot-academy/blob/main/lessons/01-create-bot.md)

**مسیر گوشی‌ات را انتخاب کن:** [آیفون و iOS](#ios) · [اندروید](#android)

<a name="ios"></a>

## مسیر آیفون | iOS

1. در **Telegram**، عکس و معرفی ربات را در [قدم ۱](#step-1) تنظیم کن و در چت ربات [اولین `/start`](#step-2) را بفرست.
2. این راهنما را در **Safari** باز کن. در همان مرورگر [وارد حساب GitHub خودت شو](#step-3) و [قالب را روی Cloudflare نصب کن](#step-4). پس از وصل‌کردن حساب GitHub، به زبانهٔ Cloudflare برگرد و **Deploy** را بزن. اگر فرم بسته شد، [مسیر برگشت به Cloudflare](#cloudflare-return) را دنبال کن.
3. وقتی صفحهٔ Worker باز شد، از BotFather توکن ربات خودت را کپی کن، به Safari برگرد و آن را در [Secret کلادفلر](#step-5) وارد کن. سپس آدرس Worker را در Safari باز کن و [اتصال ربات](#step-6) را انجام بده.
4. **«باز کردن ربات در تلگرام»** را بزن. اگر Safari گزینهٔ باز کردن Telegram را نشان داد، آن را انتخاب کن. اگر در صفحهٔ وب ماندی، برنامهٔ Telegram را باز کن و به چت همان ربات برگرد. `/start` را بفرست و از دکمهٔ «ورود به فروشگاه»، [مالکیت را ثبت کن](#step-6). بعد به [تنظیم فروشگاه](#step-7) و [پرداخت استارز](#step-8) برو.

اگر بخشی از فرم Cloudflare بیرون صفحه است، در Safari از **Page Menu** گزینهٔ **Request Desktop Website** را انتخاب کن. در بعضی نسخه‌ها این گزینه زیر **More** است. بعد از تغییر نمایش، اگر دوباره فرم ورود دیدی، با همان حساب وارد شو. [راهنمای نمایش دسکتاپ در Safari](https://support.apple.com/guide/iphone/customize-your-safari-settings-iphb3100d149/ios)

<a name="android"></a>

## مسیر گوشی اندرویدی

1. در برنامهٔ **Telegram**، تنظیم [عکس، Description و Bio](#step-1) را انجام بده. بعد در چت ربات [دستور `/start`](#step-2) را بفرست.
2. راهنما را در **Chrome** باز کن. در همان مرورگر [حساب GitHub خودت را آماده کن](#step-3) و [وارد فرم نصب Cloudflare شو](#step-4). وقتی GitHub را وصل کردی، به زبانهٔ Cloudflare برگرد و **Deploy** را بزن. اگر فرم بسته شد، [مسیر برگشت به Cloudflare](#cloudflare-return) را دنبال کن.
3. توکن را در تلگرام کپی کن. از **برنامه‌های اخیر** روی Chrome بزن تا به همان زبانهٔ Worker برگردی. [Secretها](#step-5) را وارد کن و سپس از آدرس Worker در Chrome، [ربات را به فروشگاه وصل کن](#step-6).
4. **«باز کردن ربات در تلگرام»** را بزن. اگر گوشی ازت پرسید لینک را با کدام برنامه باز کند، **Telegram** را انتخاب کن. اگر لینک در Chrome ماند، چت همان ربات را در برنامهٔ Telegram باز کن. بعد از `/start` و «ورود به فروشگاه»، [مالکیت را ثبت کن](#step-6) و به [شخصی‌سازی](#step-7) و [آزمایش پرداخت](#step-8) برو.

اگر فرم Cloudflare کامل دیده نمی‌شود، در Chrome منوی **⋮** را باز کن و **Desktop site** را بزن. [راهنمای نمایش دسکتاپ در Chrome اندروید](https://support.google.com/chrome/answer/13514529)

## قدم ۱ — عکس، Description و Bio ربات را تنظیم کن

در [BotFather رسمی](https://t.me/BotFather)، هر دستور زیر را جداگانه بفرست. بعد از هر دستور، همان رباتی را انتخاب کن که در قسمت اول ساختی.

**عکس پروفایل** با دستور زیر شروع کن و تصویری را که برای ربات آماده کردی بفرست.

```text
/setuserpic
```

**Description** معرفی‌ای است که کاربر هنگام ورود اولیه به چت ربات می‌بیند. دستور و متن نمونه زیر در دو کادر جدا قابل کپی هستند.

```text
/setdescription
```

```text
در این فروشگاه می‌توانی محصولات دیجیتال را ببینی، با استارز تلگرام خرید کنی و وضعیت سفارشت را پیگیری کنی.
```

**Bio یا About** متن کوتاهی است که روی پروفایل ربات دیده می‌شود.

```text
/setabouttext
```

```text
فروشگاه محصولات دیجیتال با پرداخت استارز تلگرام
```

پس از ذخیره، پروفایل رباتت را باز کن و عکس و Bio را بررسی کن. [راهنمای رسمی تنظیم پروفایل ربات](https://core.telegram.org/bots/features#about-text-description-and-profile-media)

<a name="step-2"></a>

## قدم ۲ — در چت خود ربات /start بزن

از BotFather بیرون بیا، چت ربات خودت را باز کن و این دستور را بفرست.

```text
/start
```

اگر ربات تازه‌ساخته هنوز به فروشگاه وصل نشده، بی‌جواب ماندن پیام در این مرحله طبیعی است. بعد از نصب و اتصال، همین دستور باید دکمهٔ «ورود به فروشگاه» را نشان بدهد.

<a name="step-3"></a>

## قدم ۳ — حساب GitHub خودت را آماده کن

1. با ایمیل خودت یک حساب رایگان GitHub بساز و ایمیل را تأیید کن. اگر حساب داری، با همان وارد شو. [ثبت‌نام در GitHub](https://github.com/signup)
2. حساب GitHub خودت را در همان مرورگر باز نگه دار و نصب قالب را از قدم ۴ شروع کن.

<a name="step-4"></a>
<a name="راهاندازی-روی-حساب-cloudflare"></a>

## قدم ۴ — قالب فروشگاه را روی Cloudflare نصب کن

1. دکمهٔ نصب قالب را باز کن و وارد حساب Cloudflare خودت شو. [راه‌اندازی فروشگاه خودم در Cloudflare](https://deploy.workers.cloudflare.com/?url=https%3A%2F%2Fgithub.com%2Frrdigitalhub01-arch%2Frr-bot-academy%2Ftree%2Fmain%2Fdigital-shop)
2. در **Set up your application**، روی **New GitHub connection** بزن و حساب GitHub شخصی‌ای را که در قدم ۳ آماده کردی وصل کن. Cloudflare یک نسخهٔ جدا از قالب در حساب خودت می‌سازد. با تیک **Create private Git repository** می‌توانی نسخهٔ خودت را خصوصی کنی.
3. در **Project name** نامی برای پروژه بگذار. اگر نام پیش‌فرض آزاد است، می‌توانی همان را نگه داری.
4. در **Select D1 database**، گزینهٔ **+ Create new** را انتخاب کن تا سفارش‌ها و موجودی این فروشگاه در دیتابیس خودش ذخیره شوند.
5. **Deploy** را بزن. پس از موفقیت ساخت، صفحهٔ Worker و آدرس HTTPS آن را باز کن. اگر Deploy خطا داد، اولین خطای ثبت‌شده در Build logs را بررسی کن.

<a name="cloudflare-return"></a>

### اگر بعد از اتصال GitHub فرم نصب را گم کردی

1. اگر به **Settings** گیت‌هاب رفتی و **Cloudflare Workers and Pages** را با وضعیت **Installed** دیدی، اتصال روی حساب GitHub نصب شده است. فهرست تب‌های Safari یا Chrome را باز کن و به تب فرم Cloudflare برگرد. اگر فرم هنوز **New GitHub connection** را نشان می‌دهد، یک بار همان تب را تازه‌سازی کن.
2. اگر فرم دیگر در تب‌ها نیست و صفحهٔ اصلی Cloudflare با عنوان **Ready when you are** باز شده، از **☰** بالا سمت چپ وارد **Workers & Pages** شو. می‌توانی اسم **Workers & Pages** را در **Search** هم جست‌وجو کنی. [باز کردن داشبورد Cloudflare](https://dash.cloudflare.com/)
3. اسم پروژه‌ات را پیدا کن. اگر نام پیش‌فرض را عوض نکردی، دنبال `rr-academy-shop` بگرد.
   - **پروژه را می‌بینی** — بازش کن و وضعیت آخرین Deploy را بررسی کن. اگر موفق شده، آدرس Worker را باز کن و به [قدم ۵](#step-5) برو. اگر هنوز در حال اجراست، از همان صفحه منتظر نتیجه بمان.
   - **پروژه را در همان حساب نمی‌بینی** — از لینک نصب زیر، فرم قالب را در همان مرورگر دوباره باز کن. در **Git account** حساب خودت را انتخاب کن و از نام پروژه و دیتابیس تا **Deploy** را طبق قدم ۴ انجام بده. [باز کردن دوبارهٔ فرم نصب قالب](https://deploy.workers.cloudflare.com/?url=https%3A%2F%2Fgithub.com%2Frrdigitalhub01-arch%2Frr-bot-academy%2Ftree%2Fmain%2Fdigital-shop)
   - **خود لینک نصب دوباره به داشبورد برمی‌گردد** — از [Create application و Connect GitHub](#cloudflare-connect-github) ادامه بده.

<a name="cloudflare-connect-github"></a>

### اگر لینک نصب دوباره داشبورد را باز کرد

1. در **Workers & Pages**، بعد از دیدن **No projects found**، روی **Create application** بزن.
2. در صفحهٔ **Make something new**، گزینهٔ اول یعنی **Connect GitHub** را بزن تا حساب و مخزن را انتخاب کنی.
3. اگر نسخه‌ای از قالب در حساب GitHub خودت ساخته شده، همان مخزن را برای Deploy انتخاب کن. اگر مخزن هنوز ساخته نشده و روش دستی را ادامه می‌دهی، اول یک [Fork از مخزن دوره](https://github.com/rrdigitalhub01-arch/rr-bot-academy) در حساب خودت بساز تا Cloudflare بتواند آن را ببیند.
4. برای کپیِ کل مخزن دوره، **Root directory** را `digital-shop` بگذار. اگر فایل `wrangler.jsonc` در صفحهٔ اول مخزن خودت است، ریشهٔ همان مخزن را نگه دار. **Deploy command** باید `npm run deploy` باشد. پروژه به دیتابیس D1 با Binding برابر `DB` نیاز دارد. [راهنمای تنظیم ساخت Cloudflare Workers](https://developers.cloudflare.com/workers/ci-cd/builds/configuration/)

<a name="step-5"></a>

## قدم ۵ — توکن و کد راه‌اندازی را در Cloudflare ثبت کن

در صفحهٔ Worker وارد **Settings → Variables and Secrets** شو و دو مقدار زیر را با نوع **Secret** اضافه کن. توکن را در همین بخش خصوصی وارد کن.

| نام Secret | مقدار |
| --- | --- |
| `BOT_TOKEN` | توکن ربات خودت از BotFather |
| `SETUP_CODE` | یک رشتهٔ تصادفی و خصوصی با حداقل ۱۶ نویسه که خودت انتخاب می‌کنی |

تغییرات را ذخیره و اعمال کن. کد راه‌اندازی را تا پایان قدم ۶ در دسترس نگه دار.

<a name="step-6"></a>

## قدم ۶ — فروشگاه را به ربات وصل کن و مالکیت را ثبت کن

1. آدرس HTTPS Worker را در مرورگر باز کن و **«اتصال ربات»** را بزن.
2. کد راه‌اندازی را وارد کن و **«اتصال ربات به فروشگاه»** را بزن. قالب وب‌هوک و دکمهٔ منوی ربات را تنظیم می‌کند.
3. **«باز کردن ربات در تلگرام»** را بزن و دستور زیر را در چت ربات خودت بفرست.

   ```text
   /start
   ```

4. **«ورود به فروشگاه»** و سپس **«راه‌اندازی مدیریت»** را بزن. همان کد راه‌اندازی را وارد کن و **«فعال‌سازی دسترسی مدیریت»** را بزن. در پایان، پنل مدیریت باید برای حساب تلگرام خودت باز شود.

<a name="step-7"></a>

## قدم ۷ — فروشگاهت را شخصی‌سازی کن

1. از **مدیریت → طراحی**، نام فروشگاه، لوگو، بنر، رنگ‌ها و متن دکمه‌ها را تنظیم و ذخیره کن.
2. در بخش محصولات، یک کالای دیجیتال قابل تحویل اضافه کن و دسته، پلن، قیمت به استارز و روش تحویلش را مشخص کن. اگر تحویل با کد یا لینک اختصاصی است، برای همان پلن از بخش موجودی، کدهای قابل استفاده وارد کن.
3. به فروشگاه برگرد و ظاهر جدید را بررسی کن. برای نمایش کالا به خریدار و ثبت خرید واقعی، تنظیمات قدم ۸ را کامل کن.

<a name="step-8"></a>

## قدم ۸ — پرداخت با استارز، تحویل و بازپرداخت را امتحان کن

1. در **مدیریت → طراحی**، لینک HTTPS شرایط خرید و مسیر پشتیبانی پرداخت را وارد و ذخیره کن. اگر فروشگاه قبلاً نصب بوده، **«به‌روزرسانی اتصال تلگرام»** را بزن تا وب‌هوک رویدادهای پرداخت را هم دریافت کند.
2. برای محصولی که آمادهٔ تحویل است، **«فعال برای پرداخت واقعی»** را روشن کن و تنظیمات را ذخیره کن. برای کالای دیجیتال، قالب با توکن همان ربات فاکتور رسمی **Telegram Stars** می‌سازد و به کلید جداگانهٔ درگاه احتیاج نداری.
3. با یک حساب خریدار جدا وارد ربات شو. محصول را به سبد ببر، شرایط خرید را تأیید کن و **«پرداخت با استارز»** را بزن. در صفحهٔ رسمی تلگرام مبلغ را بررسی کن. بعد از ثبت رسید معتبر تلگرام، وضعیت سفارش **«پرداخت شد»** می‌شود.
4. با حساب مدیر همان سفارش را از پنل تحویل بده. بعد به حساب خریدار برگرد و باز شدن کد، لینک یا جزئیات تحویل را در سفارش بررسی کن.
5. در صورت نیاز، دستور `/paysupport` مسیر پشتیبانی را برای خریدار باز می‌کند. در پنل مدیر با **«بازپرداخت کامل استارز»** می‌توانی کل مبلغ همان سفارش را برگردانی. پیش از به‌اشتراک‌گذاشتن لینک فروشگاه، خرید، تحویل و بازپرداخت را در سفارش خودت امتحان کن.

[مستندات پرداخت کالاهای دیجیتال با Telegram Stars](https://core.telegram.org/bots/payments-stars)

## اگر جایی متوقف شدی

| چیزی که می‌بینی | چه کار کنی |
| --- | --- |
| GitHub در Cloudflare انتخاب نشده | ورود با حساب شخصی و تأیید ایمیل GitHub را بررسی کن. به فرم نصب برگرد و **New GitHub connection** را بزن. |
| Deploy موفق نشده یا خطای D1 می‌بینی | Build logs و اتصال دیتابیس به Worker با نام Binding برابر `DB` را بررسی کن. |
| ربات بعد از قدم ۶ جواب نمی‌دهد | نشانی Worker را با `/api/health` باز کن، نام و مقدار Secretها و نتیجهٔ اتصال در قدم ۶ را بررسی کن. |
| پنل مدیریت دیده نمی‌شود | از دکمهٔ ربات وارد مینی‌اپ شو و «راه‌اندازی مدیریت» را با حساب تلگرام مالک تکمیل کن. |
| محصول یا دکمهٔ خرید ظاهر نمی‌شود | نمایش محصول، فعال بودن فروش واقعی، لینک شرایط و پشتیبانی و موجودی همان پلن را بررسی کن. |
| سفارش در «در حال بررسی پرداخت» مانده | سفارش‌ها را به‌روزرسانی کن و وضعیت رسید را در تلگرام بررسی کن. تحویل را بعد از ثبت «پرداخت شد» انجام بده. |

## اجرای محلی برای توسعه‌دهنده‌ها

از پوشهٔ قالب و با Node.js 24، دستورهای زیر را اجرا کن. Wrangler دیتابیس محلی را آماده و آدرس پیش‌نمایش را نمایش می‌دهد.

```sh
npm ci
npm test
npm run dev
```

در مرورگر عادی، پیش‌نمایش تمرینی کالاها و روند سفارش را می‌بینی. تست خودکار مسیر پرداخت را با پاسخ شبیه‌سازی‌شدهٔ تلگرام بررسی می‌کند. در نصب عادی، پاسخ سالم `/api/health` شامل `ok: true` و `mode: live` است. تنظیمات عمومی کاتالوگ از پنل در قالب JSON قابل ذخیره‌اند. توکن‌ها، سفارش‌ها و کدهای تحویل در فایل کاتالوگ قرار نمی‌گیرند.

[راهنمای Deploy to Cloudflare](https://developers.cloudflare.com/workers/platform/deploy-buttons/)
