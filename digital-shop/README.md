# فروشگاه تلگرام | RR Bot Academy

قالب به ربات خودت وصل می‌شود و برای کالاهای دیجیتال، فاکتور **Telegram Stars** صادر می‌کند. قیمت‌ها تعداد استارزند. پیش‌نمایش مرورگر برای تمرین است. نمونه‌های گیفت و VPN در پنل قابل ویرایش‌اند و تا زمانی که مدیر یک محصول قابل تحویل را برای پرداخت واقعی فعال کند، دکمهٔ خرید واقعی برای آن نمایش داده نمی‌شود. کارت «راهنمای استارز» به مستندات تلگرام می‌برد.

## راه‌اندازی روی حساب Cloudflare

پیش از زدن دکمهٔ نصب، وارد حساب شخصی GitHub خودت شو. در فرم Cloudflare، **New GitHub connection** را بزن و همان حساب را وصل کن. [قدم ۹-الف آموزش ساخت حساب رایگان GitHub](../lessons/02-first-menu.md#step-9-github)

[راه‌اندازی فروشگاه خودم در Cloudflare](https://deploy.workers.cloudflare.com/?url=https%3A%2F%2Fgithub.com%2Frrdigitalhub01-arch%2Frr-bot-academy%2Ftree%2Fmain%2Fdigital-shop)

برای وارد کردن مخزن از داشبورد، این مراحل را دنبال کن.

در [داشبورد Cloudflare](https://dash.cloudflare.com/)، از **Workers & Pages** یک Worker از مخزن قالب بساز. در تنظیمات ساخت، شاخهٔ پروژه را به شاخهٔ قالب و **Root directory** را به این مقدار تغییر بده.

```text
digital-shop
```

برای **Deploy command** از این دستور استفاده کن. پروژه به D1 با Binding به نام `DB` نیاز دارد. ساخت خودکار D1 و اجرای migration در مسیر استقرار تنظیم شده؛ اگر رابط Cloudflare ساخت خودکار را انجام نداد، D1 را از بخش **Storage & databases → D1 → Create database** بساز و در تنظیمات پروژه با نام `DB` به Worker وصل کن.

```sh
npm run deploy
```

در **Settings → Variables and Secrets**، دو Secret اضافه کن. مقدار توکن را از BotFather بردار و برای کد راه‌اندازی رشته‌ای تصادفی با حداقل ۱۶ نویسه انتخاب کن. کد راه‌اندازی را تا ثبت مالک نگه دار.

```text
BOT_TOKEN
```

```text
SETUP_CODE
```

بعد از ساخت پروژه، آدرس HTTPS خودت را باز کن. «اتصال ربات» را بزن، کد راه‌اندازی را وارد کن و «اتصال ربات به فروشگاه» را بزن تا Webhook و دکمهٔ منوی ربات تنظیم شوند. «باز کردن ربات در تلگرام» را بزن، دستور زیر را بفرست و «ورود به فروشگاه» را بزن.

```text
/start
```

در فروشگاه تلگرام، «راه‌اندازی مدیریت» را بزن و همان کد را وارد کن. سپس «فعال‌سازی دسترسی مدیریت» را بزن. بعد از ثبت، پنل مدیریت برای حساب تلگرام خودت باز می‌شود. برای مطمئن شدن از اتصال، پنل Cloudflare و مرورگر را ببند و دوباره از چت ربات وارد فروشگاه شو.

## فعال کردن پرداخت واقعی

1. داخل ربات، «مدیریت» و سپس «طراحی» را باز کن. لینک HTTPS شرایط خرید و یک مسیر پشتیبانی پرداخت را بگذار و تغییرات را ذخیره کن. اگر نسخهٔ قبلی نصب بوده، «به‌روزرسانی اتصال تلگرام» را بزن تا وب‌هوک رویدادهای پرداخت را هم بگیرد.
2. یک کالای قابل تحویل با قیمت به استارز بساز و «فعال برای پرداخت واقعی» را روشن کن. برای کالاهایی که با کد تحویل می‌شوند، قبل از فروش کدهای قابل استفادهٔ همان پلن را وارد کن.
3. خریدار شرایط خرید را می‌پذیرد و «پرداخت با استارز» را می‌زند. صفحهٔ رسمی پرداخت داخل تلگرام باز می‌شود. وضعیت سفارش فقط بعد از رسید معتبر تلگرام به «پرداخت شد» می‌رسد.
4. سفارش را از پنل تحویل بده. اگر مشتری به مشکل خورد، `/paysupport` او را به مسیر پشتیبانی می‌برد. برای برگشت کل مبلغ، در سفارش «بازپرداخت کامل استارز» را بزن. اگر کالا قبلاً تحویل شده، دربارهٔ دسترسی تحویل‌داده‌شده هم رسیدگی کن.
5. پیش از عمومی کردن لینک بات، با دو حساب تلگرام مسیر خرید، تحویل و بازپرداخت را روی یک محصول قابل تحویل و با مجوز مالک امتحان کن. برگشت از صفحهٔ پرداخت به‌تنهایی نشانهٔ ثبت پرداخت نیست. اگر سفارش در «در حال بررسی پرداخت» ماند، مدیر باید رسید را در تاریخچهٔ تراکنش تلگرام بررسی کند.

> اتصال واقعی به یک ربات روی حساب تازهٔ Cloudflare و تراکنش واقعی روی گوشی، جداگانه باید تأیید شوند. تست خودکار مسیر Bot API را با پاسخ‌های شبیه‌سازی‌شده بررسی می‌کند.

## اجرا و تست روی کامپیوتر

از پوشهٔ `digital-shop` با Node.js 24 اجرا کن.

```sh
npm ci
npm test
npm run dev
```

Wrangler دیتابیس محلی را می‌سازد و آدرس پیش‌نمایش را در ترمینال چاپ می‌کند. در مرورگر عادی می‌توانی از حالت تمرینی روی همان دستگاه استفاده کنی. برای باز کردن نمونهٔ محلی در دستگاه دیگر، آدرس چاپ‌شده باید از آن دستگاه قابل‌دسترس باشد.

برای بررسی سلامت مسیر آنلاین، انتهای آدرس HTTPS فروشگاهت این مسیر را باز کن. در نصب عادی نتیجهٔ سالم `ok: true` و `mode: live` است.

```text
/api/health
```

اطلاعات کاتالوگ را از پنل می‌شود در JSON ذخیره کرد. Secret‌ها، سفارش‌ها و کدهای تحویل در فایل کاتالوگ قرار نمی‌گیرند. سفارش و کد تحویل داخل تلگرام در D1 ذخیره می‌شوند. سفارش‌ها و کدهای تمرینی که از نسخهٔ قبلی باقی مانده‌اند با موجودی و پرداخت‌های واقعی قاطی نمی‌شوند.
