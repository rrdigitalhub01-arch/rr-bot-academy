# فروشگاه تلگرام | RR Bot Academy

این قالب روی ربات خودت باز می‌شود. نشان «آزمایشی» یعنی سفارش ثبت می‌شود و می‌توانی آن را از پنل تحویل بدهی، بدون اینکه پرداختی انجام شود. گیفت و VPN دادهٔ نمونه‌اند و کارت استارز به راهنمای رسمی تلگرام پیوند دارد.

## راه‌اندازی روی حساب Cloudflare

در [داشبورد Cloudflare](https://dash.cloudflare.com/)، از **Workers & Pages** یک Worker از مخزن قالب بساز. در تنظیمات ساخت، شاخهٔ پروژه را به شاخهٔ قالب و **Root directory** را به این مقدار تغییر بده.

```text
digital-shop
```

برای **Deploy command** از این دستور استفاده کن. پروژه به D1 با Binding به نام `DB` نیاز دارد. ساخت خودکار D1 و اجرای migration در مسیر استقرار تنظیم شده؛ اگر رابط Cloudflare ساخت خودکار را انجام نداد، D1 را از بخش **Storage & databases → D1 → Create database** بساز و در تنظیمات پروژه با نام `DB` به Worker وصل کن.

```sh
npm run deploy
```

در **Settings → Variables and Secrets**، دو Secret اضافه کن. مقدار توکن را از BotFather بردار و برای کد راه‌اندازی رشته‌ای تصادفی با حداقل ۱۶ نویسه انتخاب کن. کد راه‌اندازی را تا ثبت مالک نگه دار.

```text
BOT_TOKEN
```

```text
SETUP_CODE
```

بعد از ساخت پروژه، آدرس HTTPS خودت را باز کن. «اتصال ربات» را بزن، کد راه‌اندازی را وارد کن و «اتصال ربات به فروشگاه» را بزن تا Webhook و دکمهٔ منوی ربات تنظیم شوند. «باز کردن ربات در تلگرام» را بزن، دستور زیر را بفرست و «ورود به فروشگاه» را بزن.

```text
/start
```

در فروشگاه تلگرام، «راه‌اندازی مدیریت» را بزن و همان کد را وارد کن. سپس «فعال‌سازی دسترسی مدیریت» را بزن. بعد از ثبت، پنل مدیریت برای حساب تلگرام خودت باز می‌شود. برای مطمئن شدن از اتصال، پنل Cloudflare و مرورگر را ببند و دوباره از چت ربات وارد فروشگاه شو.

**وضعیت آزمون** راه‌اندازی واقعی با حساب رایگان تازهٔ Cloudflare، Webhook تلگرام و گوشی در انتظار آزمون است. مسیر بالا دستور اجرای نسخهٔ آزمایشی است.

[راهنمای Cloudflare برای Deploy button و D1](https://developers.cloudflare.com/workers/platform/deploy-buttons/)

## اجرا و تست روی کامپیوتر

از پوشهٔ `digital-shop` با Node.js 24 اجرا کن.

```sh
npm ci
npm test
npm run dev
```

Wrangler دیتابیس محلی را می‌سازد و آدرس پیش‌نمایش را در ترمینال چاپ می‌کند. در مرورگر عادی می‌توانی از حالت تمرینی روی همان دستگاه استفاده کنی. برای باز کردن نمونهٔ محلی در دستگاه دیگر، آدرس چاپ‌شده باید از آن دستگاه قابل‌دسترس باشد.

برای بررسی سلامت مسیر آنلاین، انتهای آدرس HTTPS فروشگاهت این مسیر را باز کن. نتیجهٔ سالم باید `ok: true` و `mode: training` داشته باشد.

```text
/api/health
```

اطلاعات کاتالوگ را از پنل می‌شود در JSON ذخیره کرد. Secret‌ها، سفارش‌ها و کدهای تحویل در فایل کاتالوگ قرار نمی‌گیرند. سفارش آزمایشی و کد تحویل داخل تلگرام در D1 ذخیره می‌شوند.
