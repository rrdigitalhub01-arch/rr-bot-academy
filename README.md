# RR Bot Academy | ساخت ربات تلگرام از صفر

دورهٔ فارسی RR Digital Hub برای اولین ربات تلگرامی. خروجی این پروژه یک فروشگاه تمرینی است. با `/start` منو باز می‌شود و با لمس «محصولات»، یک محصول نمونه نمایش داده می‌شود.

## از اینجا شروع کن

| درس | کار عملی | نتیجه |
| --- | --- | --- |
| [۱. ساخت ربات با BotFather](lessons/01-create-bot.md) | انتخاب نام و گرفتن توکن | ربات خودت در تلگرام باز می‌شود |
| [۲. روشن کردن ربات و ساخت اولین منو](lessons/02-first-menu.md) | اجرای نمونه و آزمایش دکمه | منوی ربات جواب می‌دهد |

درس دوم مسیر جدا برای آیفون، اندروید و کامپیوتر دارد. یک حساب تلگرام و اتصال اینترنت برای آزمایش واقعی لازم است. مسیر مستقیم آیفون از یک نوت‌بوک آماده در Google Colab استفاده می‌کند.

[کد ربات](bot.py) · [نوت‌بوک آیفون](notebooks/rr-first-bot.ipynb) · [تست‌ها](tests/test_bot.py) · [کانال RR Digital Hub](https://www.youtube.com/@rrdigitalhub)

## قالب مینی‌اپ فروشگاه

بعد از اولین منو، [قدم ۶ درس دوم](lessons/02-first-menu.md#step-6) را دنبال کن. [سورس و راه‌اندازی فروشگاه](digital-shop/README.md) در پوشهٔ `digital-shop` است.

## نمونهٔ آفلاین با Python 3.10 یا جدیدتر

بعد از باز کردن پوشهٔ پروژه در ترمینال این دستور را اجرا کن. نمونهٔ درخواست ارسال منو چاپ می‌شود و می‌توانی ساختار دکمه را ببینی.

```sh
python3 bot.py --demo
```

برای اجرای تست‌های آفلاین:

```sh
python3 -m unittest discover -s tests -v
```
